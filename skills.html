Technical Knowledge

The following are technical concepts and practical skills I have developed through coursework, laboratory investigations, and hands-on projects.

Digital Forensics
Identifying, collecting, preserving, and analyzing digital evidence. My coursework includes forensic investigations, evidence examination, and documenting investigative findings.
Forensic Disk Imaging
Using FTK Imager to acquire forensic images, examine digital evidence, and verify evidence integrity through cryptographic hash values.
File Header Analysis and Data Carving
Using HxD Hex Editor to examine hexadecimal data, identify file signatures, analyze file headers, and reconstruct files from raw digital evidence.
Chain of Custody
Maintaining documentation that records the collection, handling, transfer, storage, and examination of digital evidence to preserve its integrity and accountability.
Evidence Integrity Verification
Understanding the use of cryptographic hash functions, including MD5 and SHA-1, to compare forensic evidence and identify changes to data.
Encryption
Understanding methods used to protect sensitive information by converting readable data into an unreadable format that requires authorized access to recover.
Virtualization
Creating and configuring virtual machines using VMware Workstation and VirtualBox to support operating system testing, cybersecurity labs, and digital forensic investigations.
Cybersecurity and Network Analysis
Studying network security, threat detection, vulnerability assessment, and incident response, including the use of Wireshark and Nmap.
Data Analysis
Examining datasets to identify patterns, evaluate results, and support decision-making. My coursework includes data analysis and machine learning projects.
Technical Documentation and Reporting
Preparing investigative reports, documenting technical procedures, organizing screenshots, and communicating findings from cybersecurity and digital forensics laboratory exercises.
